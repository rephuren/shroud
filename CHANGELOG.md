# История изменений

## Не выпущено

### Добавлено
- HTML-отчёт: фильтры «все / подозрительные / странности / чистые» на чистом CSS, без скриптов
- опция `--html-sort verdict|name|size`: по умолчанию сначала самые опасные файлы

## 0.2.0

### Добавлено
- пакет и команда `shroud`, CI на Python 3.10, 3.12 и 3.14, `ruff`, `mypy`
- HTML-отчёт `--html` (экранирование, политика CSP без скриптов)
- лимиты: размер файла 256 МБ, размер изображения 100 Мпикс, защита от decompression bomb
- тесты устойчивости: обрезанные и повреждённые PNG, JPEG, GIF, BMP

### Изменено
- скриншот в тёмной красно-чёрной теме проекта
